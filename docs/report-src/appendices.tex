\section{Código fuente y evidencias}

Con el objetivo de garantizar la trazabilidad y reproducibilidad del desarrollo,
el repositorio del proyecto incluye:

\begin{itemize}
	\item Código fuente de los controladores implementados (PID, LQR, LQG, ubicación de polos, síntesis directa, etc.).
	\item Scripts de identificación y calibración en MATLAB.
	\item Firmware desarrollado para PSoC 5LP.
	\item Modelos 3D de la estructura y datos experimentales.
\end{itemize}

Las figuras, simulaciones y resultados incluidos en este informe fueron generados con la versión final del código.
